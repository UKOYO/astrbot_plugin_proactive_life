# 自主生活与主动中枢（astrbot_plugin_proactive_life）

一体化活人感中枢——贯通 **入站准入 → 主动生活与状态注入 → 记忆与群聊感知 → 出站清洗与真人节奏** 全链路，让 Bot 不再只是「有问才答」的被动应答机，而是拥有真实作息、穿衣天气感、情绪余温、人物熟悉度与自然聊天节奏的鲜活角色。

本插件已深度融合多项常见独立插件能力，一套配置统一治理，无需重复安装。

---

## 核心功能模块

插件按消息生命周期分为 **4 大链路、15 个可独立开关的功能模块**（均可在 WebUI 中枢面板一键启停；关闭总开关后完全停止介入，细项配置完整保留）：

### 1. 入站准入与反射
| 模块 | 配置开关 | 能力说明 | 已整合替代 |
| --- | --- | --- | --- |
| **全局黑名单** | `模块_黑名单` | 支持 UID 列表与批量文本解析，在入站与主动发送双入口精准拦截，可选记录日志 | `global_blacklist` |
| **消息防抖** | `模块_防抖` | 自动合并连发消息与群内多人同时 `@` 的并发请求，支持图片上限、情绪拆分与表情过滤 | `smart_debounce` |
| **撤回取消** | `模块_撤回取消` | 监测用户撤回动作，自动中止尚未发出的回复或中断防抖聚合 | `recall_cancel` |
| **戳一戳互动** | `模块_戳一戳` | 响应戳一戳事件，结合近期语境由 LLM 生成自然回应；支持「跟戳」——群里多人一起戳同一人时按概率凑一脚 | `poke_to_llm` |
| **群聊跟读** | `模块_跟读` | 识别群内连续复读刷屏，按概率与冷却规则自然跟队 | `reread` |

| **群聊主动** | `模块_群聊` | 冷场破冰、自然插话接梗；察觉被嫌烦时自动静默闭嘴；白名单群走**独立概率**（不再乘默认），分群独立覆盖策略优先 | — |

| **天气与日程穿搭** | `模块_日程` / `模块_天气` | 拉取实况与预报天气驱动每日穿搭与日程生成；按时段精准推算「此刻在做」，支持配置固定外观锚点让穿搭只换衣服不改长相，同时注入主动与被动对话 | `life_scheduler` / `weather` |

## 拟人化与沉浸增强

- **定位（重要）**：本插件只做「**行为与时间骨架**」——什么时候开口、别抢答、作息节奏、去客服八股、生活状态注入。**口癖、标点习惯、动作括号 `{}`、称呼关系与文风 100% 交还给你在 AstrBot 里配置的原人设**（8～30KB 那份）。插件不示范怎么写、不覆盖说话风格；`拟人_说话方式强度` 默认 `gentle`（只压客服/百科/总结腔，不限句式与标点），主动开口与摸鱼的请求体也不再重复拼接人设（宿主 `system_prompt` 已带完整人设，还能命中 Prefix Cache）。
- **被动回复临时注入（`life_inject.py`）**：以低优先级临时拼入用户消息侧（不污染持久化系统提示词，保护 Prompt Cache），将「此刻时间/活动」「固定外观」「今日穿搭」「实时天气」「此刻心情」「可自然提起的心事」「跨会话人物记忆」自然带入日常聊天。
- **按需分层注入（`日程_被动按需注入`，默认开）**：常态只给极短时间锚点 + 心情 + 人物档案；对方问到「在干嘛 / 今天」才带「此刻在做 + 今日日程」，问到「穿什么 / 穿搭」才带「固定外观 + 今日穿搭」。日程块紧贴用户消息、近因效应极强，这样低智模型也不会聊着聊着强行背日程。
- **身份锚定（`拟人_身份锚定`，默认开）**：防止模型被问到时自曝底层模型/厂商。触发范围分两档：**模型/厂商探测词**（什么模型、哪家做的、是不是 AI、具体模型名）私聊与群聊都注入；**日常社交试探**（你是谁呀、我是谁）只在群聊注入——私聊这类问句交给你的人设自己处理。约束只陈述边界（不报模型名、不自称 AI、不解释提示词），**不给台词模板**，语气仍由人设决定。
- **心事被动频控（`motive_pool.peek_passive_hint`）**：同一条心事最多被动提示 2 次、两次间隔至少 30 分钟，且只在「在吗 / 干嘛呢 / 好无聊」这类没有明确主题的短句时才递，避免连续几轮复读同一件事。
- **动态打字停顿（`rhythm_trimmer.human_pause`）**：气泡间隔按下一段字数 + 随机抖动计算（0.35~2.5s），长回复超过 6 条时走快速档，短句快、长句慢；`节奏_间隔秒数=0` 时后续气泡真连发（只有首段保留 0.5s 保底防乱序）。
- **作息驱动的回复延迟（`modules/reply_delay.py`，默认关）**：读缓存日程的「此刻在做」，命中洗澡/开会/路上这类忙碌词时晚几秒再回（睡眠/洗澡给满额，其余 6 成）。指令、急事词（救命/赶紧/医院…）、戳一戳自动豁免；纯内存计算，零模型消耗。
- **模型档位（`拟人_模型档位`）**：`lite` 档把 `<conversation_scene>` 拍平成两行纯文本（省格式 Token、弱模型不被标签稀释），并把临时注入预算压到 300 字。
- **闲聊限长（`拟人_闲聊限长启用`，默认关）**：短句、非代码、无工具链的请求临时压 `max_tokens`（默认 160）并提高 `frequency_penalty`（0.35），物理上防小作文八股；响应后立刻还原。**默认关闭的原因**：本版 AstrBot 的 `ProviderRequest` 没有请求级参数，只能临时改 provider 的 `custom_extra_body`，多群并发时另一个会话可能吃到限长；单活跃会话自用可以放心打开（详见 `modules/token_guard.py` 顶部说明）。
- **固定外观锚点（`日程_外观锚点`）**：填一段角色固定外貌（发色 / 瞳色 / 脸型 / 体型等），例如「黑色长直发、琥珀色眼睛、圆脸」。生成日程时作为不可改写前提、穿搭只换衣服；主动与被动注入都会一并带上，避免模型每次描述自己长相都不一样。留空不启用，不影响原有行为。
- **说话方式引导（`modules/speech_style.py`）**：提供 `gentle` / `normal` / `strict` 拟人语气强度，内建幂等标记与技术排障/代码长文场景自动豁免，闲聊像朋友随口聊、干活时不受短句束缚；按模型家族追加一句避坑（DeepSeek 禁「不是…而是…」与破折号，Gemini/GPT 禁寒暄与末尾反问，Claude 禁文学比喻与说教）。
- **跨会话人物档案（`modules/person_memory.py`）**：持久化记录互动次数、熟悉度、上次聊到的话题与 7 天无互动熟悉度自然衰减，避免把刚发来的本轮消息误当成「上次说到」。
- **跨轮情绪状态机（`mood.py`）**：被冷落会委屈、被回应会开心、被喊闭嘴会闷闷不乐、摸鱼有收获会兴致高昂，持久化落盘并按衰减周期回归平静。
- **人设自动提炼与身份管理（`identity.py`）**：支持从当前 AstrBot 人格配置提取身份设定，并结合穿搭与天气生成更贴合角色口吻的日程安排。

## WebUI 中枢面板

在 AstrBot 后台进入 **「插件 → 自主生活与主动中枢 → 中枢面板」** 即可打开（通过插件页 Bridge 通信，不支持浏览器直接打开本地 HTML）。

界面采用黑白编辑式排版，支持浅色 / 深色 / 等宽三种主题、缩放调节与自适应布局，运行状态默认每 4 秒自动刷新。

### 13 个独立分栏

| 分组 | 分栏 | 功能概览 |
| --- | --- | --- |
| **总览** | **总览** | 重叠插件冲突提醒、近期活动日志、预设一键应用、心事池增删、全局调度与运行脉冲 |
| **互动** | **私聊** | 主动破冰、静默阈值、追问挂念策略 |
| | **群聊** | 破冰、插话、闭嘴判定及分群专属覆盖配置 |
| | **戳一戳 / 艾特** | 戳一戳响应、群聊跟读与撤回取消参数 |
| | **黑名单** | 全局黑名单 ID 列表、批量粘贴解析、主动发送拦截开关 |
| **内容** | **黑话** | 群黑话词典浏览、手动释义编辑、触发归纳分析与一键清空 |
| | **摸鱼** | 后台探索间隔、概率、搜索方向与模式 |
| | **日程** | 今日穿搭与日程展示、天气城市配置、带补充要求重新生成、手动改写保存 |
| | **出站清洗** | 思考过滤、八股清洗规则与拟人说话方式强度 |
| **系统** | **节奏** | 分段字数阈值、单次条数上限、打字间隔与标点/颜文字修剪 |
| | **防抖** | 合并窗口、图片上限、情绪拆分与实时聚合统计 |
| | **身份** | 角色人设重载、特征提炼与称呼映射 |
| | **上下文** | 场景感知、短期总结、成员印象配置与当前状态 |

### 面板 API

| 路由 | 方法 | 说明 |
| --- | --- | --- |
| `/astrbot_plugin_proactive_life/panel/status` | `GET` | 获取完整运行快照（冲突检测、日程/天气、黑名单、黑话、防抖、情绪、心事池等） |
| `/astrbot_plugin_proactive_life/panel/config` | `GET` / `POST` | 读取或热写入插件配置（白名单由 `_conf_schema.json` 自动生成，当前共 **203 项**配置键，单一真源不再手工四处对齐） |
| `/astrbot_plugin_proactive_life/panel/action` | `POST` | 执行面板动作：`schedule_generate`、`schedule_save`、`preset_apply`、`motive_add`、`motive_delete`、`persona_reload`、`persona_synthesize`、`slang_update_meaning`、`slang_analyze`、`slang_clear` |

### 配置热生效机制

`plugin.cfg` 采用直接映射 `AstrBotConfig` 的活视图（`_LiveConfig`）：无论在中枢面板还是 AstrBot 插件配置页修改并保存，均立即落盘并实时生效，无需重载插件。

### 数据持久化

全部运行数据通过 `StarTools.get_data_dir("astrbot_plugin_proactive_life")` 原子读写落盘：

- `schedule_data.json`：今日穿搭与日程（优先级高于旧版 `life_scheduler`）
- `weather_cache.json`：实况与预报天气缓存
- `motive_pool.json`：心事与话题池
- `private_state.json`：私聊交互计数与追问状态
- `person_memory.json`：跨会话人物熟悉度与上次话题记录
- `mood_state.json`：跨轮情绪状态持久化
- `mute_until.json`：各群静默截止时间
- `slang_dict.json`：群黑话词典（按需自动保存）

`life_scheduler` · `smart_debounce` · `context_aware` · `global_blacklist` · `recall_cancel` · `poke_to_llm` · `reread` · `thinking_filter` · `prose_polish` · `slang_miner` · `weather` · `gif_vision_helper`

## 部署与维护

- **工具隔离**：内置热点工具命名为 `pl_bilibili_hot` 与 `pl_tieba_hot`，避免与第三方检索插件同名冲突。
- **修改生效**：修改配置即时热生效；修改 Python 源码后需在 AstrBot 后台重载插件。
- **回归测试**：修改代码后可在插件目录运行全量测试：
  ```bash
  pytest tests
  ```
- **发布打包**：`python build_release.py` 会在 `dist/` 下生成 `astrbot_plugin_proactive_life-v<版本>.zip`，自动排除 `.git/`、`__pycache__/`、`.pytest_cache/` 与运行态 `data/`（避免覆盖用户已有数据或泄露本地开发记录）。
- **维护约定**：配置项只在 `_conf_schema.json` 里加一次。`config_defaults.DEFAULT_CONFIG` 与 `panel_config.EDITABLE` 都由它自动生成；面板显示名在 `pages/panel/app.js` 的 `LABELS` 里补一条中文即可（缺失时回退显示原始键名）。

## 更新日志

- **v1.5.26**
