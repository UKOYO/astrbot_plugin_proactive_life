# 自主生活与主动中枢（astrbot_plugin_proactive_life）

让 Bot 不再只是「有问才答」的被动应答机，而是真正拥有自己的生活节奏——会主动找人搭话、会追问没聊完的话题、会在群里自然破冰与接梗、会在闲暇时自己上网摸鱼、会记住上一轮的情绪余温，还会把「今天穿了什么、此刻在做什么」自然地带进对话里。

本插件为**一体化主动中枢**，已深度整合多项原本独立的插件能力，无需重复安装。

---

## 核心功能模块

插件由 **7 个可独立开关的模块**组成，每个模块在 WebUI 对应分栏的**第一项**即为其总开关：

| 模块 | 配置开关 | 核心能力 |
| --- | --- | --- |
| **私聊** | `模块_私聊` | 长时间静默后主动破冰；抛出问题未获回复时适时追问 |
| **群聊** | `模块_群聊` | 冷场破冰、自然插话接梗；察觉被嫌烦时自动静默闭嘴 |
| **摸鱼** | `模块_摸鱼` | 空闲时自主上网探索（内置搜索 / MCP 搜索 / 热点榜单），并将收获沉淀至心事池 |
| **节奏** | `模块_节奏` | 将长回复拆分为短句分段发送，自动修剪句末标点与颜文字，模拟真人打字节奏 |
| **日程** | `模块_日程` | 每日按提示词生成专属穿搭与日程，动态计算「此刻在做」，注入私聊与群聊语境 |
| **防抖** | `模块_防抖` | 自动合并连发消息与多人同时 `@` 的并发请求，汇总后再交由模型处理 |
| **上下文** | `模块_上下文` | 场景感知（识别对话对象）、短期对话总结、群成员印象画像 |

> **总开关机制**：总开关为父级门控（默认全开）。关闭后该模块将完全停止介入（不监听、不注入、不生成），但底层细项配置会完整保留，重新开启即可无缝恢复。

### 拟人化增强能力

- **跨轮情绪状态机（`mood.py`）**：被冷落时会委屈、被回应会开心、被喊闭嘴会闷闷不乐、摸鱼有收获则兴致高昂。情绪会直接影响回复语气，并随时间（默认 3 小时）自然衰减回平静（内存存储，重启清空）。
- **成员印象画像**：持续统计成员的互动频率、提问习惯、发图偏好与发言长度，让 Bot 接话时能够「因人而异」。
- **开口动机多样化**：当心事池为空时，从「想念 / 无聊 / 报备 / 分享 / 小情绪 / 关心」等维度随机切入，避免每次开场白千篇一律。
- **日程语境驱动**：依据「此刻在做」动态决定话题方向（如打游戏→聊卡关、看番→聊剧情、刚睡醒→犯困）。

## WebUI 中枢面板

在 AstrBot 后台依次进入 **「插件 → 自主生活与主动中枢 → 中枢面板」** 即可打开。面板通过插件页 Bridge 通信，**不支持直接用浏览器打开本地 `index.html`**。

界面采用极简黑白编辑式排版（固定左侧导航、细线分隔、大留白），支持浅色/深色主题、等宽字体切换、字号缩放（`localStorage` 持久化）、粒子背景与毛玻璃外框。状态默认每 4 秒自动刷新，关闭页面不影响后台运行。

### 8 大独立分栏

| 分栏 | 功能概览 |
| --- | --- |
| **总览** | 冲突提示、近期活动日志、私聊与群聊实时状态、节奏/摸鱼概览、全局调度 |
| **私聊** | 主动开口与追问的全部触发参数 |
| **群聊** | 破冰、插话、闭嘴策略，以及与标题同级的「群专属分区」独立配置 |
| **摸鱼** | 后台探索开关、触发间隔、概率，支持自定义搜索方向与模式 |
| **节奏** | 分段字数阈值、单次条数上限、发送间隔、标点与颜文字过滤规则 |
| **日程** | 今日日程展示 → 生成配置（提示词、服装库、模型） → 手动改写穿搭与安排 |
| **防抖** | 合并窗口、图片上限、情绪拆分、表情过滤，以及实时状态监控（合并中会话 / 已吸收消息） |
| **上下文** | 场景感知、短期总结、成员印象配置与当前分析状态 |

### 日程页特性

- **动态生成与灵活干预**：每日到达「日程生成时刻」自动生成一次；也可随时点击「重新生成」并附带补充要求（如「今天下雨，别安排出门；穿红色连衣裙」），或直接在底部「改写日程」中手动编辑保存。
- **防重复穿搭库**：内置 15 种穿搭风格与可编辑提示词模板，生成时会自动规避近几天穿过的风格。
- **数据优先级**：生成结果优先写入本插件的 `schedule_data.json`；若文件不存在，则自动回退读取旧版 `life_scheduler` 的数据。

### 面板 API

| 路由 | 方法 | 说明 |
| --- | --- | --- |
| `/astrbot_plugin_proactive_life/panel/status` | `GET` | 获取实时状态快照（含冲突检测、今日日程、防抖统计） |
| `/astrbot_plugin_proactive_life/panel/config` | `GET` / `POST` | 读取或写入插件配置 |
| `/astrbot_plugin_proactive_life/panel/action` | `POST` | 执行面板动作（当前仅支持 `schedule_generate` / `schedule_save`） |

> 为防止误写破坏配置结构，`POST /panel/config` 仅接受 `web_api.py` 中 `EDITABLE` 白名单定义的 **96 个配置键**，其余未知键将被自动丢弃并在响应的 `rejected` 字段中返回。

### 配置热生效机制

`plugin.cfg` 采用直接映射 `AstrBotConfig` 的活视图（`_LiveConfig`），而非启动时的静态快照：

- **面板修改**：写入并调用 `save_config()` 落盘，运行时视图立即读取到最新值。
- **后台修改**：在 AstrBot 插件配置页修改同一份 `AstrBotConfig`，无需重载插件即可实时生效。

## 架构与代码组织

| 文件 / 目录 | 核心职责 |
| --- | --- |
| `main.py` | 插件主类、核心协调循环、事件钩子、模块总开关、热点工具注册 |
| `web_api.py` | 面板 API 路由、状态快照构建、配置白名单读写、插件冲突检测 |
| `common.py` | 共享常量、路径解析、日程只读访问、模型获取、错误特征识别 |
| `handler_base.py` | 各业务 Handler 共用的 Mixin（日志、情绪读写、模块开关校验） |
| `agent_runner.py` | 统一的 MainAgent 装配与调度（私聊 / 破冰 / 摸鱼共用） |
| `private_handler.py` / `group_handler.py` / `worker_handler.py` | 私聊、群聊、摸鱼三条核心业务链路 |
| `context_scene.py` | 场景消息采集、对象推断、短期总结与成员印象 |
| `mood.py` | 跨轮情绪状态机与衰减逻辑 |
| `schedule_gen.py` | 日程生成引擎（提示词装配 + 创意池 + 结果校验） |
| `debounce.py` | 消息防抖管线、租约锁与多模态内容抽取 |
| `motive_pool.py` | 心事与话题池管理 |
| `rhythm_trimmer.py` | 回复分段与标点/颜文字修剪 |
| `name_resolver.py` | 会话与用户名称解析 |
| `pages/panel/` | WebUI 面板前端资源（HTML / JS / CSS） |

> **维护提示（配置四处对齐）**：增删配置项时，必须同步维护 `_conf_schema.json`、`web_api.EDITABLE`、`app.js LABELS` 与 `main.DEFAULT_CONFIG`（当前均严格对齐为 **96 项**）。

### 数据持久化

所有持久化文件均位于 `StarTools.get_data_dir("astrbot_plugin_proactive_life")`：

- `motive_pool.json`：心事与话题池（与 `qzone`、`life_scheduler` 共享读取）
- `private_state.json`：私聊交互计数与追问挂念状态
- `schedule_data.json`：中枢生成的今日日程（读取优先级高于 `life_scheduler`）
- `mute_until.json`：各群组的静默截止时间戳

*注：`MoodStore`、`MemberStore`、`SummaryStore` 均为纯内存存储，重启后自动清空。*

### 插件冲突检测

启动日志与面板总览会自动检测以下功能重叠（仅作只读提示，不会自动停用其他插件）：

- `life_scheduler` 处于启用状态，且本插件的日程自动生成已开启
- `smart_debounce` 处于启用状态，且本插件的防抖模块已开启
- `context_aware` 处于启用状态，且未开启「让位 contextaware」选项

## 部署与使用要点

- **路由与面板**：面板接口在 `initialize()` 中自动注册，重载插件后自动重挂（注册失败仅记录警告，不阻断主循环）；`pages/panel/` 由 AstrBot 自动发现，无需手动配置路由。
- **工具命名隔离**：内置热点工具已注册为 `pl_bilibili_hot` 与 `pl_tieba_hot`，避免与 `astrbot_plugin_BitTorrent` 等插件产生同名冲突。
- **摸鱼搜索装配**：摸鱼链路会自动挂载三类搜索能力——AstrBot 内置搜索（按 `websearch_provider` 映射）、用户配置的 MCP 工具，以及本插件的两个热点工具。
- **生效方式**：修改 Python 源码后需**重载插件**；仅调整配置项则即时热生效。
- **排障指引**：若某项功能未按预期触发，请优先查看面板悬浮错误提示与启动日志，系统现已透出具体失败原因。

## 已知限制与边界

- **前端文件粒度**：后端核心模块已完成拆分，前端 `pages/panel/app.js` 体量仍较大，后续视迭代节奏逐步模块化。
- **并发访问**：共享状态（`private_state`、`motive_pool` 及各内存 Store）暂未加细粒度锁；后台总结、闭嘴判定与节奏补发任务已纳入 `terminate()` 统一取消。
- **日程校验**：日程的「补充要求」目前作为最高优先级提示词注入，暂未做逐项断言校验（例如「别穿裙子」不会触发硬性拦截）。
- **内存状态**：三项内存 Store 重启即清空，如需跨重启保留需自行扩展持久化逻辑。
- **冲突处理**：冲突检测仅提供告警提示，需用户手动停用重叠插件。
